# Tokly identity

The user selected Tokly. The app, Xcode project/scheme, widget display name and icon now use Tokly. Bundle IDs, Widget kind, URL scheme and data paths remain stable to preserve existing installations.

- Quanta — measurable units; preferred candidate for an AI usage meter.
- Abaco — inspired by the abacus; counting and clarity.
- Rill — a small stream; quiet ongoing usage flow.

Tally and Gauge were excluded from this shortlist because current same-category products already use those names:
https://github.com/jettoai/tally
https://studiogrid.io/studio-gauge/

This is a creative shortlist, not a name-availability determination.

## Icon concept

Artifact: ../assets/branding/icon-concept.png
Generated with the built-in image_gen tool. Installed as the app icon, packaged as assets/branding/Tokly.icns.

Prompt:
Use case: logo-brand. Create a polished original macOS app icon concept for a local AI usage meter. One icon only, no letters, no words, no numbers, no other brands. A compact memorable mark: three luminous offset stacked rounded tiles forming a rising measured rhythm, suggest accumulated units and clarity rather than a generic bar chart. Dark deep-indigo rounded-square app tile, restrained electric blue to soft teal highlights, subtle material depth and precise soft lighting, strong silhouette readable at tiny sizes, generous inner margins. Front view, centered, square 1024x1024 composition. No surrounding mockup, no decorative objects, no watermark. This is a proposed identity for an as-yet-unnamed native macOS utility; do not use any existing company logo.
